# 65DSD-bully-algorithm

### Passo a passo para rodar o projeto:

Construir JAR caso ele não exista:

``mvn -DskipTests package``


Executar apontando para a pasta de classes (alterar o id d nó a ser executado 1, 2, 3):

``java -cp target/classes org.example.Node 1 nodes.conf``
